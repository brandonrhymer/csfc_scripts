# Nessus plugin archive download

Read `download-plugins.ps1` help and preview with `-WhatIf`. Supply
`-DownloadUri` and `-OutputPath`; existing output is protected, incomplete downloads
are cleaned up, and no credentials or source URLs are built in. Validate the
archive using your approved process before import. Download success is not
an authenticity check or a successful plugin update.


See [validation](../../docs/attachment-validation.md).
